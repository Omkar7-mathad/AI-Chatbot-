# 🤖 Artificial Intelligence Chatbot

## 📌 Artificial Intelligence Chatbot

A Java-based AI chatbot developed for interactive communication.  
The chatbot integrates a Graphical User Interface (GUI) for real-time user interaction and implements rule-based logic with basic Natural Language Processing (NLP) techniques.

---

## 🚀 Project Objectives

✔ Create a Java-based chatbot for interactive communication  
✔ Use Natural Language Processing (NLP) techniques  
✔ Implement machine learning logic or rule-based answers  
✔ Train the bot to respond to frequently asked questions  
✔ Integrate with a GUI for real-time interaction  

---

## 🛠️ Technologies Used

- Java
- Swing (GUI)
- OOP Concepts
- Event Handling
- Basic NLP Techniques
- Rule-Based Logic

---

## 🧠 Working Principle

The chatbot:

- Accepts user input through GUI
- Processes text using basic NLP techniques (keyword matching, pattern recognition)
- Matches input with predefined FAQ responses
- Generates intelligent rule-based replies
- Displays output instantly in the chat window

---

## 🖥️ GUI Features

- Chat display area
- User input text field
- Send button
- Scrollable conversation window
- Exit functionality
